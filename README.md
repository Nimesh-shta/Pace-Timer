# Pace Timer 🏃

A simple and easy-to-use running and walking pace timer for Android.

## 📱 Download the App

👉 **[Download Pace Timer APK](../../releases/latest)**

Download the APK from the latest GitHub Release and install it on your Android phone.

> **Note:** You may need to allow your browser/file manager to install apps from unknown sources when installing the APK.

---

## ✨ Features

- 🏃 Running timer
- 🚶 Walking timer
- ⏱️ Custom workout/pace timing
- 🔊 Sound controls
- 🔇 Mute/unmute audio
- 📊 Workout completion screen
- 📱 Simple and clean Android interface
- ⚡ Lightweight and easy to use

---

## 🎯 What is Pace Timer?

Pace Timer is a simple Android app designed to help with running and walking workouts.

Set up your activity, start the timer, and follow your workout without unnecessary complexity.

## 📥 Installation

1. Download the latest APK from the **[Releases](../../releases)** page.
2. Open the downloaded APK on your Android phone.
3. Allow installation from unknown sources if Android asks.
4. Install the app.
5. Open **Pace Timer** and start your workout.
